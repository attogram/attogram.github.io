The site header, layout, and styling have been updated to improve clarity and readability.

Key changes include:
- A new header structure with a consistent navigation menu across the portfolio and blog.
- Implementation of a modern sans-serif typography using system fonts.
- A constrained page layout with a maximum width of 800px for better reading focus on large screens.
- An updated color palette featuring an off-white background and deep charcoal text for improved contrast.
- Refined styling for project cards on the portfolio page.

These updates aim to provide a cleaner and more accessible experience for all visitors.
